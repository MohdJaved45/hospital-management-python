# 🏥 Hospital Management System (Python)

A console-based Python project built using **Object-Oriented Programming (OOP)** concepts to manage patients, doctors, and appointments efficiently with local file storage.

---

## 🚀 Features

* **Patient Management:** Add, search, update, display, and delete patient records.
* **Doctor Management:** Track doctor details with specialization options (Cardiologist, Dentist, Surgeon, etc.).
* **Appointment Scheduling:** Book and view patient-doctor appointments seamlessly.
* **File I/O Data Persistence:** Save all records locally into a structured `hospital_data.txt` file.

---

## 🛠️ Tech Stack & Requirements

* **Language:** Python 3.x
* **Storage:** Text File Handling (`hospital_data.txt`)
* **Paradigm:** Object-Oriented Programming (OOP)
